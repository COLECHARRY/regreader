# 寄存器综合管理工具 v1.1 使用手册 & README

## 项目名称
**寄存器综合管理工具（Register Analyzer）**  
**版本**：v1.1  
**语言**：中文界面  
**主要功能**：可视化解析硬件寄存器描述表格（Excel），支持交互式读写模拟、位域高亮、修改状态追踪、代码生成、复位等功能。

## 功能亮点

- 支持**批量上传**多个寄存器描述 Excel 文件
- 自动识别常见表头（中英文混杂均可）
- 支持**多地址精确搜索**（如：`0x0000&&0x0004&&0x0010`）
- 实时**十六进制输入**修改寄存器值
- **点击位图**翻转单个 bit（模拟写 1/写 0）
- **字段重叠检测**并红色高亮警告
- 修改过的寄存器**橙色高亮**显示
- 一键**生成 Verilog / C 风格写寄存器代码**（支持单个 / 全部）
- 支持**全部复位**到 Excel 描述的默认值
- 数据**自动保存在浏览器本地**（localStorage），刷新页面不丢失
- 支持**导出**合并后的寄存器映射表为 Excel

## 支持的 Excel 表格格式（推荐列名）

| 推荐列名（不区分大小写） | 说明                             | 是否必填 | 示例值                     |
|--------------------------|----------------------------------|----------|----------------------------|
| Offset / 偏移            | 寄存器相对基地址的偏移（16进制） | 必填     | 0x0000 / 0x04             |
| RegName / 寄存器名       | 寄存器名称                       | 推荐     | CTRL / STATUS             |
| Width / 宽度 / Bitwidth  | 寄存器位宽（通常写在寄存器首行） | 推荐     | 32 / 16                   |
| Bit / BitRange / 位域    | 字段位范围                       | 必填     | 31:0 / 15 / 7:0           |
| FieldName / 字段名       | 字段名称                         | 必填     | EN / MODE / RSV           |
| RW / 属性 / Access       | 读写属性                         | 推荐     | RW / RO / WO / Rsvd       |
| ResetValue / 复位值      | 复位值（支持 Verilog 风格写法）  | 推荐     | 32'h0000_0000 / 16'd0     |
| Description / Desc / 描述| 字段详细说明                     | 可选     | Enable bit of module      |

**支持的复位值写法示例**（均可被正确解析）：

```
32'h0000_1234
16'hABCD
8'd255
4'b1010
32'd1000
```

## 使用步骤

### 1. 打开工具

直接在浏览器中打开 `regAnalyzer.html` 文件（推荐 Chrome / Edge / 新版 Firefox）

### 2. 上传寄存器描述表格

1. 点击顶部蓝色按钮 **“上传表格”**
2. 选择一个或多个 `.xlsx` / `.xls` 文件
3. 工具会自动解析并合并显示

> **提示**：支持一次性上传多个模块的寄存器表，工具会自动按 Offset 排序。

### 3. 浏览与交互

- **寄存器头部** 显示：
  - 地址（Offset）
  - 寄存器名称
  - 当前**十六进制值**（可直接编辑）
  - 位图（bit fields）可视化
  - **代码** / **复位** 两个小按钮

- **点击位图中的任意一位** → 该 bit 立即翻转（0↔1）

- **直接修改十六进制输入框** → 回车或失焦后立即更新位图

- **字段名称/描述高亮**：输入搜索关键字后相关内容会黄色高亮

- **重叠字段警告**：如果同一个 bit 被多个字段占用，会显示红色 ⚠️ 警告并高亮整行

### 4. 搜索功能

在顶部搜索框输入以下内容均可：

- 寄存器名 / 字段名 / 描述中的任意文字
- 单个地址：`0x0000`
- 多个地址（精确匹配）：`0x0000&&0x0004&&0x0010`

### 5. 常用操作按钮

| 按钮           | 功能                             | 快捷方式          |
|----------------|----------------------------------|-------------------|
| **全部复位**   | 将所有寄存器恢复到 Excel 描述的默认值 | —                 |
| **生成所有代码** | 把当前显示的所有寄存器写寄存器代码复制到剪贴板 | —                 |
| **代码**（单个） | 仅复制当前寄存器的写寄存器代码   | 点击寄存器行右侧  |
| **复位**（单个） | 仅恢复当前寄存器到默认值         | 点击寄存器行右侧  |
| **导出**       | 导出当前所有解析后的寄存器表为 Excel | —                 |
| **清空**       | 清空所有数据并刷新页面           | —                 |

### 6. 生成的代码示例

```c
// 单个寄存器
write_reg(0x0000<<2, 0x00001234); // EN[0:0]=0x1, MODE[2:1]=0x2, RSV[31:3]=0x0

// 多个寄存器（全部生成）
write_reg(0x0000<<2, 0x00001234); // EN[0:0]=0x1, ...
write_reg(0x0004<<2, 0x80000000); // IRQ_EN[31:31]=0x1, ...
```

## 常见问题解答（FAQ）

**Q1：上传文件后表格是空的？**  
A：请检查 Excel 表头是否包含 `Offset`、`Bit`、`FieldName` 等关键列，且偏移地址格式为 `0x0000` 风格。

**Q2：为什么有些字段显示重叠警告？**  
A：说明同一个 bit 位置被多个字段定义了（可能是表格错误），工具已用红色高亮提醒。

**Q3：刷新页面后数据丢失了？**  
A：不会！数据会保存在浏览器本地存储（localStorage），除非你主动点击“清空”按钮。

**Q4：支持多大位宽的寄存器？**  
A：理论上支持 1~128 位（受 BigInt 限制），实际测试 64 位完全没问题。

**Q5：如何快速跳转到某个寄存器？**  
A：在搜索框输入 `0xXXXX&&0xYYYY` 即可只显示指定寄存器。
