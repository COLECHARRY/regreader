## Summary

**Three new files added** to implement a git monitoring tool with AI analysis:

| File | Purpose |
|------|---------|
| `git-monitor.js` | Main script - tracks commits, generates diffs, calls AI to analyze changes |
| `git-monitor-config.json` | Configuration (version doc directory + API key) |
| `.git-monitor-state.json` | Tracks last analyzed commit and timestamp |

**What it does:**
1. Compares current HEAD to last analyzed commit
2. Collects new commits and uncommitted changes
3. Sends the diff to MiniMax AI API for analysis
4. Generates version documentation in `docs/versions/`

**⚠️ Security concern:** The API key in `git-monitor-config.json` is exposed in plain text. Should be moved to environment variables.
